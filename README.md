# MAD700 Practice Lab

Android (Java + XML) practice lab for MAD700, in the CA-test style: **// TODO** incomplete code, no fill-in-the-blank exam questions.

- **Flow mode**: the lecturer's own questions in order (CA test, ReTEST, sample tests, Semester 1 test, study-guide exercises, Smart Pantry code): TODO skeleton, instant marks (QUESTION / YOUR ANSWER / FEEDBACK / MODEL ANSWER), then "interpret it".
- Quizzes, mock short answers and // TODO checks use the same instant rubric: mark like 2/4; full marks show an ALTERNATIVE wording; partial marks name what was right, what was missing and why; no marks explain the gap and the key idea, then the model answer. Model answers are attempt-gated.
- Resource map (P1-P5 + light review, with a full map page per pointer), lessons, fill-ins (practice only), reels (verified YouTube links), printable cheatsheet, timed mock.
- Progress is stored in your browser (localStorage + IndexedDB `mad700lab`); Settings has a sync file for phone/laptop.
- **Videos**: the scope reteach, Lesson 01 (RecyclerView), Lesson 02 (Fragments, DialogFragment and the Manifest) and the recap are on the Videos page and inside each pointer's map with chapter jumps (L03-L05 appear here as they are made). Full quality is in `mad700_lab_videos_v2.zip` (unzip beside `index.html`). On this hosted copy the page offers a **lite copy** (854p, 12 fps, mono) stored in `videos_lite/` as base64 text, because the git connector can only push text; the page decodes it in your browser (5-10 MB, a few seconds) and chapter buttons load it automatically.
- **Study tools**: per pointer, the Vaia study set + tag to filter (P1: Android basics ... P5: SQLite) and the NotebookLM notebook with the sources to tick and prompts for a quiz, a video overview and flashcards.


Open `index.html` (any static host works; it also runs from a local folder).

**Keycards:** this lab holds none of its own. They already exist in Vaia (tag filter per pointer) and in the MAD700 NotebookLM notebook; each pointer links to both.
